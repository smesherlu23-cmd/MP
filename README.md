# Симулятор боя для варгейма

Настольный инструмент ГМ: моделирует боестолкновение двух батальонов и выдаёт
человекопонятный исход — потери в личном составе и технике, остаточную
боеспособность, организацию, снабжение и пошаговый журнал с объяснением, почему
цифры изменились.

Техническое задание — [`SPEC.md`](SPEC.md), заметки для разработки —
[`CLAUDE.md`](CLAUDE.md).

## Возможности

- конструктор подразделений: батальон собирается из элементов (роты, штаб,
  миномётная батарея, разведвзвод, бронегруппа, тыл, инженерный взвод);
- настройка условий боя: местность, время суток, погода, укрепления,
  разведданные, приказы, задача и сид;
- пошаговый расчёт с журналом: у каждой строки потерь и изменения морали видно,
  какие модификаторы сработали и с какими числами;
- итоговый отчёт с экспортом в Markdown, HTML и CSV;
- массовое моделирование: N прогонов, вероятности исходов, p10/p50/p90 потерь,
  графики, таблица прогонов и повтор любого из них по сиду;
- редактор всех коэффициентов прямо из интерфейса, без перезапуска;
- тумблеры опциональных параметров: выключенный параметр не участвует в
  расчёте и скрывается в интерфейсе.

Никаких внешних сервисов и сети — всё работает офлайн.

## Установка

```bash
python -m pip install -e ".[dev]"      # или: pip install flet matplotlib pydantic PyYAML pytest ruff
```

Нужен Python 3.11 или новее.

## Запуск

```bash
cd wargame_sim
python app.py                                     # десктопное приложение
python cli.py --demo --seed 42                    # один бой в консоли
python cli.py --demo --runs 100 --out batch.md    # 100 прогонов и сводка
python cli.py --scenario data/scenarios/scn_demo.json --seed 42 --runs 100
```

Полный список ключей — `python cli.py --help`.

## Воспроизводимость

У каждого боя один `master_seed`. Повторный прогон с тем же сидом, теми же
подразделениями и тем же конфигом даёт побитово идентичный результат, включая
журнал; сид сохраняется вместе с результатом, и любой прогон из массового
моделирования открывается точным повтором.

## Проверка

```bash
python -m pytest          # тесты
python -m ruff check .    # линтер
```
