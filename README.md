# WarSim — симулятор боя для ГМ

Настольное приложение (Windows) для мастера варгейма или ролевой войны: шаблоны подразделений и конкретные силы сторон (потери боя закрепляются за ними), пошаговый расчёт боя двух сторон с журналом причин и массовое моделирование для балансировки. Подходит для любой эпохи — от отряда в 2–3 бойца до полков в тысячи человек: всё, что влияет на расчёт, задаётся в наборе правил и редактируется в программе.

## Возможности

- **Понятная навигация.** Главная с незавершёнными боями («Продолжить») и недавно изменённым; навигатор слева с разделами (Главная, Сценарии, Силы, Шаблоны, Бои, Наборы правил, Справка, Настройки) и кнопкой «+ Новый…» в каждом; вкладки открытых объектов сверху, как в браузере (сжимаются, а не поместившиеся — в списке «▾»); кнопки «назад / вперёд» (Alt+← / Alt+→, боковые кнопки мыши); над заголовком каждой страницы — где вы находитесь. Окно без системной шапки: кнопки окна встроены в верхнюю полосу.
- **Быстрый переход и отмена.** Ctrl+K находит любые силы и шаблоны (в том числе вложенные части — откроется с выделенным узлом), сценарий, тип или раздел набора правил, бой и команду. Ctrl+Z / Ctrl+Y отменяют и повторяют любые правки, включая удаления. В конструкторе работают стрелки, Ins, Ctrl+D, Del и F2.
- **Работа с клавиатуры:** Tab проходит по пунктам навигатора, строкам списков и записям журнала с разбором (Enter открывает, ↑/↓ — соседний пункт); меню «⋯» открывается Enter или ↓, пункты выбираются стрелками, Esc закрывает и возвращает фокус; подсказки «?» показываются при переходе на значок клавишей Tab; Esc закрывает окна и диалоги.
- **Наборы правил под эпоху:** классы целей, дистанции, каталог типов (люди, расчётное вооружение, техника) с огневой мощью по классам и дистанциям, приказы, уровни опыта и командиров, условия боя (местность, время суток, погода — и свои категории), укрепления, разведданные, свои правила вида «если… то характеристика ×N», уровни исхода, около 90 коэффициентов и порогов. Ненужные механики (топливо, связь, поломки…) выключаются галочкой. В комплекте два примера: «Универсальный» (XX–XXI век) и «Линейная тактика» (XVIII–XIX век) — у каждого есть свои шаблоны, силы и готовый сценарий («атака на высоту 212»; «бой у переправы»: пехотная бригада с батареей и гусарами против батальона за редутами с батареей и кирасирами в резерве, с планом ввода резервов — исход не предрешён, около трети побед атакующих).
- **Шаблоны — штатное устройство:** единое дерево любой глубины — от бойца до армии; уровни (отделение, взвод, рота… или свои: «копьё», «баннер», «полк») задаются в наборе правил. Два вида: **оргсхема** и **список**. У любого узла — состав по штату (типы из каталога) и подчинённые; эшелон, штаб, «стоять насмерть», атака и защита в %, теги. Приказа и состояния у шаблона нет — он нужен только для того, чтобы создавать по нему войска. Шаблон вставляется в другой как связанная копия (сразу ×N с нумерацией: «1-й взвод», «2-й взвод»…); если шаблон изменился, копии помечаются и обновляются по одной или все сразу. Сводка: численность, техника, огневая мощь. Набор правил виден и меняется прямо в редакторе; пустой шаблон подсказывает, с чего начать.
- **Силы — конкретные подразделения сторон:** создаются по шаблону («Создать силы по шаблону…» ×N, «+ Новые силы», прямо из сценария) и сгруппированы по принадлежности (сторона, страна, отряд). У сил своё состояние — в строю, раненые и техника в ремонте, опыт, мораль, слаженность, готовность, боезапас, топливо, снаряжение, усталость, связь, снабжение; всё **наследуется от старшего**, пока не задано явно. Потери боя записываются в конкретные силы, а не в шаблон, которым пользуются все: батальон, потрёпанный в первом бою, во второй выйдет с некомплектом. Если шаблон изменился, силы предлагают обновиться — устройство и штат берутся из шаблона, названия, потери и состояние сохраняются. Командиров нет ни в шаблонах, ни в силах — они задаются в сценарии и в бою.
- **Сценарий:** две стороны и сколько угодно сил на каждой — «+ Добавить на сторону…»: готовые силы целиком или **только нужные части** (рота из батальона, батальон из бригады — с состоянием старшего) либо новые силы по шаблону ×N; перетаскиванием из навигатора. Одно подразделение не участвует в сценарии дважды — программа предупредит. **Приказы задаются в сценарии** — у подразделения на стороне и при желании у его частей. Силы, перетащенные на другие, придаются им на этот бой («отделить» — вернуть). У подразделения на стороне можно снять галочки с частей, которые в этом бою не участвуют, не меняя сами силы. Укрепления и разведданные, задачи сторон (удержать, захватить, нанести потери, сохранить силы, разведать, не допустить бегства), условия, начальная дистанция, лимит ходов, соотношение сил.
- **Пошаговый бой.** Каждый ход: события плана боя → обнаружение → инициатива → огонь и выбор целей → потери → подавление → движение → боезапас, топливо, поломки → усталость → мораль и слаженность → проверки (уничтожение, паника, отход, потеря штаба, распад формирования, ввод резервов). Между ходами ГМ меняет приказы, условия, дистанцию, состояние и состав элементов, снабжение, вводит подкрепления раньше плана — всё записывается в журнал и воспроизводится. Любой ход и решение можно отменить (↶, Ctrl+Z на вкладке боя) или вернуться к концу любого хода — бой повторяется с теми же бросками.
- **План боя** в сценарии: подход подкреплений, смена приказа (ввод резерва, отход), смена условий (ночь, дождь) на заданном ходу — с вероятностью и разбросом по времени. Работает и в бою, и в массовых прогонах, где ГМ не вмешивается.
- **Журнал с объяснениями:** у каждой записи о потерях, морали, обнаружении, инициативе и проверках есть разбор множителей («Приказ «Атака» ×0.75, Холмы ×1.1, Подавление 34% ×0.8…»).
- **Командиры — решение ГМ, а не шаблона:** командир есть у каждого формирования, имена не нужны. Стартовый уровень (от «некомпетентного» до «выдающегося» или «без командира») задаётся в сценарии («Командиры в начале боя») — так и массовые прогоны моделируют сильного или слабого командира; по ходу боя ГМ меняет его в таблице сил — удачное решение или ошибка в конкретный момент. Всё пишется в журнал и воспроизводится.
- **Большие бои читаемы:** одинаковые имена уточняются старшими («2-й взвод · 3-я рота»), потери и мораль за ход сводятся по формированиям, таблица сил и оргсхема сворачиваются, у групп — итоги ветки.
- **Итоги:** потери людей (убито / ранено / пропало) и техники по типам (уничтожено / повреждено / брошено), остаточная боеспособность, организация, мораль, снабжение, выполнение задач, уровень исхода со строкой «Решило: …», ключевые события, разбивка по формированиям, графики по ходам. Полный отчёт — для ГМ; **донесение для каждой стороны** — свои цифры точно, противник диапазоном по уровню разведданных (туман войны). **«Записать итоги в силы»** — потери, раненые и техника в ремонте, мораль, усталость и боезапас на конец боя переходят в силы, участвовавшие в бою (для кампаний); повторная запись — только с подтверждением, Ctrl+Z отменяет.
- **Массовое моделирование:** N прогонов сценария — вероятности исходов, средние потери, медиана, 10–90%, мин–макс, гистограммы, список прогонов с сортировкой; любой прогон открывается как полноценный бой. Экспорт CSV.
- **Случайность и повторы:** каждый бой случайный; «Переиграть» — новый бой, «Повторить этот же бой» — те же броски кубиков (с вашими решениями или без).
- **Бои занимают мало места:** на диск пишется журнал без подробного уровня и разборов (в 7–9 раз меньше: бой дивизия на дивизию — около 1,5 МБ вместо 11); подробности восстанавливаются повтором боя, когда их открывают. Все бои сценария, завершённые или вообще все бои удаляются разом (навигатор, настройки).
- **Новый набор правил** создаётся на основе существующего (по умолчанию — того, с которым работаете) или пустым.
- **Данные — JSON-файлы** в папке данных (по умолчанию «Документы/WarSim», у портативной версии — рядом с .exe; шаблоны — в `formations/`, силы — в `forces/`): их можно копировать, передавать другим ГМ (экспорт/импорт) и править вручную.
- **Защита данных.** Наборы правил, шаблоны, силы и сценарии автоматически копируются в `backups/` при запуске и раз в час, если что-то изменилось (хранятся 10 последних копий и по одной за 14 дней); копию можно сделать и вернуть в Настройках — текущее состояние перед этим само сохраняется. Удалённое (включая бои) попадает в корзину `trash/` на 30 дней и возвращается из Настроек или кнопкой «Вернуть» в уведомлении. Файл, который не читается (повреждён, пуст), не теряется: он откладывается в `damaged/`, остальное загружается, а программа сообщает об этом и подсказывает, где взять копию.

## Как получить .exe

Сборка для Windows выполняется автоматически в GitHub Actions (workflow «Сборка»): откройте последний запуск во вкладке **Actions** репозитория и скачайте артефакт **WarSim-windows**. Внутри два файла:

- `WarSim-<версия>-setup.exe` — установщик;
- `WarSim-<версия>-portable.exe` — портативная версия без установки (данные хранятся в папке `WarSim-data` рядом с файлом).

Собрать самостоятельно на Windows (нужен Node.js 22):

```
npm ci
npm run dist:win
```

Готовые файлы появятся в папке `release`.

## Разработка

```
npm ci            # зависимости
npm start         # собрать и запустить настольное приложение (Electron)
npm run dev       # интерфейс в браузере (данные — в localStorage), с горячей перезагрузкой
npm test          # тесты движка
npm run test:e2e  # проверки интерфейса в браузере (Playwright; первый раз: npx playwright install chromium)
npm run typecheck # проверка типов
npm run sim       # демо-бой в консоли; npm run sim -- сценарий.json правила.json --runs 500
```

### Устройство

```
src/engine/   движок боя — чистый TypeScript без зависимостей от интерфейса
  types.ts          модель данных (правила, подразделения, сценарий, состояние боя, итоги)
  forces.ts         шаблоны и силы: создание по шаблону, ссылки сценария на силы, запись итогов боя
  units.ts          дерево подразделений: наследование, шаблоны и их обновление, перемещение
  coefficients.ts   описание всех коэффициентов и порогов с значениями по умолчанию
  defaults.ts       наборы правил-примеры, фабрики, демо-данные
  context.ts        система модификаторов и справочники
  battle.ts         создание боя и фазы хода
  outcome.ts        итоги, задачи, уровень исхода
  interventions.ts  вмешательства ГМ и воспроизведение боя
  montecarlo.ts     массовое моделирование и статистика
  report.ts         текстовый отчёт
src/ui/       интерфейс (React): вкладки, редакторы, бой, прогоны, справка
electron/     главный процесс: окно, диалоги; protect.ts — файлы данных, резервные копии, корзина
scripts/      запуск движка из командной строки
tests/        тесты движка и файлов данных
e2e/          проверки интерфейса в браузере (Playwright)
```
