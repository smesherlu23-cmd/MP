# WarSim — симулятор боя для ГМ

Настольное приложение (Windows) для мастера варгейма или ролевой войны: конструктор подразделений, пошаговый расчёт боя двух сторон с журналом причин и массовое моделирование для балансировки. Подходит для любой эпохи — от отряда в 2–3 бойца до полков в тысячи человек: всё, что влияет на расчёт, задаётся в наборе правил и редактируется в программе.

## Возможности

- **Понятная навигация.** Навигатор слева с разделами (Главная, Сценарии, Подразделения, Бои, Наборы правил, Справка, Настройки) и кнопкой «+ Новый…» в каждом; вкладки открытых объектов сверху, как в браузере; кнопки «назад / вперёд» (Alt+← / Alt+→, боковые кнопки мыши); над заголовком каждой страницы — где вы находитесь. Окно без системной шапки: кнопки окна встроены в верхнюю полосу.
- **Быстрый переход и отмена.** Ctrl+K находит любое подразделение (в том числе вложенное — откроется с выделенным узлом), сценарий, тип или раздел набора правил, бой и команду. Ctrl+Z / Ctrl+Y отменяют и повторяют любые правки, включая удаления. В конструкторе работают стрелки, Ins, Ctrl+D, Del и F2.
- **Наборы правил под эпоху:** классы целей, дистанции, каталог типов (люди, расчётное вооружение, техника) с огневой мощью по классам и дистанциям, приказы, уровни опыта и командиров, условия боя (местность, время суток, погода — и свои категории), укрепления, разведданные, свои правила вида «если… то характеристика ×N», уровни исхода, около 90 коэффициентов и порогов. Ненужные механики (топливо, связь, поломки…) выключаются галочкой. В комплекте два примера: «Универсальный» (XX–XXI век) и «Линейная тактика» (XVIII–XIX век).
- **Конструктор подразделений:** единое дерево любой глубины — от бойца до армии; уровни (отделение, взвод, рота… или свои: «копьё», «баннер», «полк») задаются в наборе правил. Два вида: **оргсхема** и **список**. У любого узла может быть свой состав по типам (штат, в строю, раненые/в ремонте) и подчинённые; приказ, эшелон, связь, снабжение, опыт, мораль, слаженность, готовность, боезапас, топливо, снаряжение, усталость и состояние техники **наследуются от старшего**, пока их не задали явно. Командир и его уровень, штаб, «стоять насмерть», атака и защита в %. Сводка с подчинёнными: численность, некомплект, техника, огневая мощь, риск паники. Набор правил подразделения виден и меняется прямо в редакторе; пустое подразделение подсказывает, с чего начать.
- **Шаблоны и придание:** подразделение из библиотеки вставляется как связанная копия (сразу ×N с нумерацией: «1-й взвод», «2-й взвод»…). Если шаблон изменился, копии помечаются, и их можно обновить по одной или все сразу — названия, потери и состояние копий сохраняются. Подразделения перетаскиваются мышью внутри схемы, из навигатора и между сторонами сценария; переданное другому подразделению помечается как «придано» с указанием, откуда.
- **Сценарий:** две стороны, копии подразделений (структуру каждого можно раскрыть прямо в сценарии), укрепления и разведданные, задачи сторон (удержать, захватить, нанести потери, сохранить силы, разведать, не допустить бегства), условия, начальная дистанция, лимит ходов, соотношение сил.
- **Пошаговый бой.** Каждый ход: обнаружение → инициатива → огонь и выбор целей → потери → подавление → движение → боезапас, топливо, поломки → усталость → мораль и слаженность → проверки (уничтожение, паника, отход, потеря штаба, распад формирования, ввод резервов). Между ходами ГМ меняет приказы, условия, дистанцию, состояние и состав элементов, снабжение — всё записывается в журнал и воспроизводится.
- **Журнал с объяснениями:** у каждой записи о потерях, морали, обнаружении, инициативе и проверках есть разбор множителей («Приказ «Атака» ×0.75, Холмы ×1.1, Подавление 34% ×0.8…»).
- **Итоги:** потери людей (убито / ранено / пропало) и техники по типам (уничтожено / повреждено / брошено), остаточная боеспособность, организация, мораль, снабжение, выполнение задач, уровень исхода, ключевые события, разбивка по формированиям, графики по ходам. Отчёт копируется в буфер для игроков. Результаты можно вернуть в подразделения (для кампаний).
- **Массовое моделирование:** N прогонов сценария — вероятности исходов, средние потери, медиана, 10–90%, мин–макс, гистограммы, список прогонов с сортировкой; любой прогон открывается как полноценный бой. Экспорт CSV.
- **Случайность и повторы:** каждый бой случайный; «Переиграть» — новый бой, «Повторить этот же бой» — те же броски кубиков (с вашими решениями или без).
- **Бои занимают мало места:** на диск пишется журнал без подробного уровня и разборов (в 7–9 раз меньше: бой дивизия на дивизию — около 1,5 МБ вместо 11); подробности восстанавливаются повтором боя, когда их открывают. Все бои сценария, завершённые или вообще все бои удаляются разом (навигатор, настройки).
- **Новый набор правил** создаётся на основе существующего (по умолчанию — того, с которым работаете) или пустым.
- **Данные — JSON-файлы** в папке данных (по умолчанию «Документы/WarSim», у портативной версии — рядом с .exe): их можно копировать, передавать другим ГМ (экспорт/импорт) и править вручную.

## Как получить .exe

Сборка для Windows выполняется автоматически в GitHub Actions (workflow «Сборка»): откройте последний запуск во вкладке **Actions** репозитория и скачайте артефакт **WarSim-windows**. Внутри два файла:

- `WarSim-<версия>-setup.exe` — установщик;
- `WarSim-<версия>-portable.exe` — портативная версия без установки (данные хранятся в папке `WarSim-data` рядом с файлом).

Собрать самостоятельно на Windows (нужен Node.js 22):

```
npm ci
npm run dist:win
```

Готовые файлы появятся в папке `release`.

## Разработка

```
npm ci            # зависимости
npm start         # собрать и запустить настольное приложение (Electron)
npm run dev       # интерфейс в браузере (данные — в localStorage), с горячей перезагрузкой
npm test          # тесты движка
npm run test:e2e  # проверки интерфейса в браузере (Playwright; первый раз: npx playwright install chromium)
npm run typecheck # проверка типов
npm run sim       # демо-бой в консоли; npm run sim -- сценарий.json правила.json --runs 500
```

### Устройство

```
src/engine/   движок боя — чистый TypeScript без зависимостей от интерфейса
  types.ts          модель данных (правила, подразделения, сценарий, состояние боя, итоги)
  units.ts          дерево подразделений: наследование, шаблоны и их обновление, перемещение
  coefficients.ts   описание всех коэффициентов и порогов с значениями по умолчанию
  defaults.ts       наборы правил-примеры, фабрики, демо-данные
  context.ts        система модификаторов и справочники
  battle.ts         создание боя и фазы хода
  outcome.ts        итоги, задачи, уровень исхода
  interventions.ts  вмешательства ГМ и воспроизведение боя
  montecarlo.ts     массовое моделирование и статистика
  report.ts         текстовый отчёт
src/ui/       интерфейс (React): вкладки, редакторы, бой, прогоны, справка
electron/     главный процесс: окно, файлы данных, диалоги
scripts/      запуск движка из командной строки
tests/        тесты движка
e2e/          проверки интерфейса в браузере (Playwright)
```
