# Изменения

Формат: раздел на версию, сверху — новая. Раздел версии попадает в описание релиза на GitHub.

## [Не выпущено]

### Окно
- Под любой экран. В узком окне (уже 900 точек: ноутбук с масштабом 150%, окно у края экрана) боковая панель скрыта и выезжает поверх страницы; инспектор (журнал боя, свойства), когда странице мало места, — тоже поверх неё. Разделы набора правил в узком окне — строкой сверху, список типов — над карточкой типа. Кнопки боя не уходят за край панели инструментов.
- Масштаб «Авто» (по умолчанию): на экране больше 2560×1440 — крупнее (4K при масштабе Windows 100% — 150%), Ctrl+0 возвращает «Авто». Окно при первом запуске — по размеру экрана, на маленьком экране — развёрнуто. На сверхшироком экране сценарий, набор правил и команда — колонкой до 2400 точек посередине.
- Главная, каталоги, настройки и справка в развёрнутом окне и во весь экран — по центру, на очень широком экране — шире; пустой полосы справа нет. Во весь экран (F11) у панели инструментов нет места под кнопки окна.
- На карточке сил одна кнопка «Восстановить…» вместо семи: лечение, ремонт, пополнение (из резерва или из другого подразделения), отдых, боезапас и топливо — в одном окне, одной записью.
- Страница команды: раненые за всё время и сейчас на лечении; в таблице боёв — колонка «Ранено», у потерь — убито / ранено / пропало.
- Каталог типов: эталон для сравнения (по умолчанию — рядовой боец); под каждым числом — значение эталона и разброс у типов того же вида, в огневой мощи — во сколько раз больше эталона.
- В списках «по умолчанию» значение не повторяется: эшелон, опыт, дальность участка.
- Огневая поддержка: без поля названия — средство называется по типу.
- Уведомления, пока открыто окно, — слева внизу и не закрывают его кнопки.

### Теги
- Тег — особенность типа (кавалерия, ночное видение, сапёр): задаётся только у типа в наборе правил. У подразделения тегов больше нет — оно получает теги типов своего состава; они видны в карточке подразделения («Дополнительно»), в таблице типов и в окне элемента в бою.
- Теги подразделений из прежней версии в расчёте не участвуют; карточка показывает их с кнопкой «Убрать». Бои, начатые до обновления, считаются как раньше.
- Подсказки тегов у типов и в своих правилах — из одного списка (теги типов, тег разведки, теги из правил). Тег в условии правила, которого нет ни у одного типа, подсвечивается.

### Документация
- Руководство ГМ: цифры пересчитаны прогонами после «Расчёт оружия принимает огонь» (эквиваленты оружия, ориентиры исходов, опыт и командиры).
- Справка и README — по нынешнему окну; `npm run sim` берёт силы сценария из папки данных.

## [1.0.0] — 2026-11-01

Первая версия под номером. Всё, что было сделано до неё, — в README («Возможности»); здесь — последний круг перед выпуском.

### Надёжность
- Ошибка на странице больше не оставляет пустое окно: «Ошибка на этой странице» с переходом на «Главное», копированием отчёта и перезагрузкой. Сбой загрузки данных, ошибки в кнопках и падение окна — тоже сообщением.
- Окно закрывается только после записи на диск последних правок.
- Импорт проверяет содержимое файла: испорченный или чужой файл не попадает в данные, программа говорит, чего в нём не хватает.
- Файлы и данные из более новой версии программы — с предупреждением.
- Electron 44.10.1 (исправление безопасности).

### Расчёт боя
- Расчётное оружие (миномёт, пулемёт, ПТ-средство, орудие) принимает огонь по числу расчёта: миномёт с расчётом из 4 человек — как 4 бойца, а не как один. Раньше взвод из одних миномётов терял вдвое больше стрелкового. Оборона с таким оружием теперь держится дольше: пример «атака на высоту 212» удаётся атакующему примерно в каждом четвёртом бою вместо каждого второго. Старые бои воспроизводятся как раньше; выключается коэффициентом «Расчёт оружия принимает огонь».

### Окно
- Кнопки в панели инструментов — с рамкой; «+ Создать» — кнопка с подписью; меню программы — значок ☰; в бою одна отмена вместо двух.
- «Приёмы работы в окне» на «Главном»: правый щелчок, Пробел, F2, панель свойств, избранное — пока не закроете.
- Стрелки списков ▾, как принято в Windows.
- Оргсхема: мельче до 75%, у скрытого края — стрелка прокрутки; название блока не уходит под «⋯».
- Таблица сил в бою помещается в окне шириной 1100 px без прокрутки вбок.
- Графики боя: отметки ключевых событий (план боя, решения ГМ, паника, выход из боя) с подсказкой.
- Справка: строка не шире ~80 знаков.
- Массовое моделирование: последний результат каждого сценария сохраняется между запусками.

### Выпуск
- Релизы на GitHub по тегу `v<версия>` с установщиком, портативной версией и этим списком.
- Проверка настоящего приложения (Electron, файлы данных) при каждой сборке для Windows.
